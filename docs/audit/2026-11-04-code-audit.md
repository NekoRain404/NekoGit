## 2. 缺陷清单

### P0 — 阻断级

#### AUD-001 桌面端两个 IPC 命令没有 ACL 权限

- 前端调用：`app/composables/desktop-runtime/commands.ts:63,70`（`desktop_set_review_state`、`desktop_set_current_github_state`）
- 调用点：`app/plugins/desktop-open-current-github.client.ts:36`、`app/components/dashboard/pr/PRReviewWorkspace.vue:365`
- 缺失：`src-tauri/capabilities/default.json` 无对应 `allow-*`；`src-tauri/permissions/autogenerated/commands/` 无对应 `.toml`
- 证据：`npx tauri permission list` 只有 33 个 `allow-desktop-*`；生成的 `__app-acl__` 为 33 个命令 × allow/deny
- 影响：原生菜单状态同步被永久禁用；`Ctrl+Shift+G/L`、`Ctrl+Alt+C`、`Ctrl+Shift+C`、`Ctrl+Alt+O`、Review 菜单全部失效
- 修复：补齐 permission 文件与 capability；让 `build.rs` 显式声明 `AppManifest::commands`，避免后续命令再次漏生成；加 CI 校验

#### AUD-002 CI 基线失败

- GitHub Actions `31133890158`：Format、Rust 失败
- Rust 失败原因：`.output` / `.node-runtime` 不存在，`tauri-build` 校验 `bundle.resources` 报错
- `.github/workflows/ci.yml:164-168` 未准备资源目录，也未运行 `cargo fmt --check`
- 本地 `pnpm fmt:check` 失败 24 个文件；`cargo fmt --check` 失败 3 个文件
- 修复：CI 中准备资源或跳过资源校验；增加 `cargo fmt --check`；统一格式化；修复 lint 配置

### P1 — 直接影响功能

#### AUD-003 lint 配置近乎空跑

- `.oxlintrc.json:5` 将 `correctness` 设为 `off`，且未启用其他规则
- 探针 `{ a: 1, a: 2 }`、`if (obj = null)` 均无告警
- 影响：CI Lint 假绿，无法阻止常见错误
- 修复：启用 `correctness`（至少 `error`），按需启用 `no-unused-vars` 等规则，修复存量问题

#### AUD-004 CI 检查重跑端点错误

- `server/api/repos/[owner]/[repo]/pulls/[pull_number]/checks/[run_id]/rerun.post.ts:20` 使用 `/check-runs/{run_id}/rerun`
- GitHub 端点为 `/check-runs/{check_run_id}/rerequest`，且仅适用于 GitHub App 创建的 check run
- Actions job 需 `POST /repos/{owner}/{repo}/actions/jobs/{job_id}/rerun`
- 影响：`PRChecksPanel.vue:120` 重跑按钮永远失败
- 修复：优先 `rerequest`；失败时从 `details_url` 解析同仓库 Actions job ID 并调用 job rerun；无法处理时给出明确错误
- 验证：新增 URL 解析单测 + 路由级错误映射测试

#### AUD-005 1–100 MB 文件无法下载/预览

- `server/api/repos/[owner]/[repo]/raw/[...path].get.ts:45` 要求 `encoding === 'base64'`
- `server/utils/repo-contents-utils.ts:62` 同样要求
- GitHub Contents API 对 1–100MB 返回 `encoding: "none"` 和空 `content`
- 影响：大文件 raw 下载 404，文件预览为空
- 修复：contents 返回 `sha` 时改用 Git Blobs API（base64，≤100MB）；>100MB 返回明确的 413；预览端返回可识别的“文件过大”元数据
- 验证：新增策略/元数据单测；对 raw 处理逻辑做 mock 测试

#### AUD-006 非 HEAD 提交的行内评论使用错误 commit_id

- 选择历史 commit：`app/components/dashboard/pr/PRReviewWorkspace.vue:63-78`
- 文件按 `commitSha` 获取，但提交 review 的 `commitId` 始终是 head（`:77`），提交体使用该值（`app/composables/usePRReview.ts:785-793`）
- 影响：评论错位或被 422 拒绝
- 修复：为 `usePRReview` 增加独立的 `submitCommitId`，使用当前选中 commit；非 HEAD 时保持行内评论可用但明确提交 commit
- 验证：composable 单测断言提交 payload 使用选中 SHA

#### AUD-007 Issues/PR 的 closed/merged 筛选与排序失效

- `server/api/issues.get.ts:17`、`server/api/pulls.get.ts:17` 硬编码 `is:open`
- UI 提供 closed/merged：`app/components/dashboard/widgets/QuickFilters.vue:61-67`
- 统计基于 open-only 列表：`app/pages/dashboard.vue:744-770`
- `sort:updated-desc` 放在 `q` 中（`:21`），GitHub Search API 需要 `sort` / `order` 参数
- 实测：加/不加该 qualifier，`total_count` 相同但首条结果不同，说明未按 updated 排序
- 修复：issues/pulls API 支持 `state=open|closed|all` 与 `merged=1`；默认列表显式传 `sort=updated&order=desc`；筛选变化时重新请求并更新分页/统计
- 验证：新增查询构造单测；现有筛选 UI 手工/组件测试

#### AUD-008 合并 PR 后 UI 仍显示 open

- `app/components/dashboard/PRDetail.vue:348-361` 将 merge 响应 `{sha, merged, message}` 展开进 PR 对象
- 未设置 `state` / `merged_at`，也未重新拉取详情
- 修复：合并成功后设置 `state: 'closed'`、`merged_at`，或调用 `fetchPullRequestDetails()`
- 验证：组件或纯函数测试覆盖合并后状态

#### AUD-009 本地分支操作后 PR 关联徽章过期

- `associatedPullRequest` 仅在 git status refresher（`refreshers.ts:108`）和创建 PR 后刷新
- 分支切换/创建/远端检出（`useLocalRepositoryPanel.ts:345/383/423`）与 `runDesktopLocalRepositoryGitAction`（`:227-251`）均未刷新
- 影响：旧分支的 PR 徽章残留，`Create PR` 被错误隐藏
- 修复：所有改变 branch/upstream 的操作结束后调用 `refreshAssociatedPullRequest()`；或 watch `gitStatus.branch`
- 验证：composable 测试断言分支切换后调用刷新

#### AUD-010 持久会话下 “Checkout Locally” 不显示

- `PRDetail.vue:124,227` 依赖 `desktopAvailable`
- `useDesktopRuntime` 的 `available` 只有调用 `loadRuntimeInfo()` 后才为 true；`PRDetail` 未调用
- 修复：PRDetail `onMounted` 调用 `loadRuntimeInfo()`，或把可用性初始化改为 `isTauri()`
- 验证：组件测试/手工桌面验证

## 5. 安全结论

已具备：

- CSRF double-submit + Origin/Referer 同源校验（实测 403）
- PAT / personal unlock 失败限流（实测第 8 次 429）
- 会话加密、session secret 0600、desktop 生成密钥
- Octokit 错误 Authorization redact（实测无 token 泄漏）
- 本地 Git 分支/提交/路径参数校验，命令无 shell 插值
- 外部 URL、深链、单实例激活 allowlist
- API 路由均有 session 鉴权；health 使用 HMAC challenge

需补强：AUD-021/023/024/025/026，以及 Web 安全头（AUD-022）。

未发现可远程利用的认证绕过、命令注入或 RCE。
